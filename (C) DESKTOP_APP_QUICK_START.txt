🔧 TROUBLESHOOTING
───────────────────────────────────────────────────────────────────────────────

Problem: "Port 3000 already in use"
Fix:     lsof -ti:3000 | xargs kill -9
         npm start

Problem: "npm install fails"
Fix:     npm cache clean --force
         npm install again

Problem: "Electron won't start"
Fix:     npm install --save-dev electron@latest
         npm start

Problem: "JARVIS won't start from app"
Fix:     • Check: python3 --version
         • Check: /Users/ruthish/Projects/Jarvis.ai/run.py exists
         • Test: python /Users/ruthish/Projects/Jarvis.ai/run.py (in terminal)
         • Check logs in Logs tab

Problem: "Settings won't save"
Fix:     • mkdir -p ~/.jarvis
         • Check permissions: ls -la ~/.jarvis/
         • Try saving again

Problem: "Logs empty"
Fix:     • Start JARVIS from app
         • Give it a command
         • Toggle auto-refresh OFF and back ON
         • Check: tail -f /Users/ruthish/Projects/Jarvis.ai/data/logs/jarvis.log

💡 TIPS
───────────────────────────────────────────────────────────────────────────────

• Restart JARVIS after changing wake word in Settings
• Lower speech speed (150-160) sounds more natural
• Check Logs if JARVIS isn't responding
• Use Command History to see what skills were used
• Disable skills you don't use to save resources
• Colors in Logs: Red=problem, Orange=warning, Blue=info
• Latency chart updates every time you give a command
