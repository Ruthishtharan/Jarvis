Learning

Each cycle harvests your conversations, retrains the local intent router, evaluates it on unseen phrasings, and only promotes the new model if it beats the current one. A loop that always promotes walks itself downhill. It never trains on its own predictions — only on commands the regex tier matched, which are free ground truth.
