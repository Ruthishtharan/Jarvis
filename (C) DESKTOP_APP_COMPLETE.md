## 🚨 Troubleshooting

| Problem | Cause | Solution |
|---------|-------|----------|
| App won't start | Dependencies missing | Run `npm install` |
| Port 3000 in use | React server already running | Kill with `lsof -ti:3000 \| xargs kill -9` |
| Electron crashes | Node version too old | Update Node: `brew upgrade node` |
| JARVIS won't start | Python not found | Check: `python3 --version` |
| Settings won't save | No `.jarvis` folder | Create: `mkdir -p ~/.jarvis` |
| Logs empty | No activity | Start JARVIS from the app |
| Charts broken | Browser cache | Clear: Cmd+Shift+Delete |
