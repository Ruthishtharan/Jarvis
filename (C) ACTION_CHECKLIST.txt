🎯 IF SOMETHING GOES WRONG
───────────────────────────────────────────────────────────────────────────────

"Web search not working"
→ Run: pip install ddgs
→ Restart JARVIS

"Menu bar app crashes"
→ Run: pip install pyobjc-framework-Cocoa pyobjc-framework-AppKit
→ Try again

"Coding assistant doesn't respond"
→ Check .env has GROQ_API_KEY
→ Check internet connection
→ Check logs: tail -f data/logs/jarvis.log

"Startup daemon not working"
→ Run: python cli/(C) startup_manager.py --status
→ Check logs: cat data/logs/startup.log
